# Pedidos

Sistema de toma de pedidos de la distribuidora.

- Delphi 5 Enterprise
- Base de datos Paradox via BDE (alias PEDIDOS en C:\PEDIDOS\DATOS)
- Informes en Crystal Reports 8 (carpeta \INFORMES)

Para instalar en un PC nuevo: instalar BDE, crear el alias y copiar el ejecutable.
Usuario por defecto: VENTAS. Los informes solo los ve jefatura.

Ultima actualizacion: marzo 2009
